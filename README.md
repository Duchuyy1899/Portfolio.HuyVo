# Võ Đức Huy - Personal Portfolio Website

Dự án Portfolio cá nhân của **Võ Đức Huy** (Front-end Web Developer & Graphic Designer).

## 🚀 Hướng dẫn cài đặt & khởi chạy trên máy tính

### 1. Yêu cầu hệ thống
- Cài đặt **Node.js** (khuyến nghị phiên bản LTS 18 trở lên hoặc 20+): [https://nodejs.org](https://nodejs.org)

### 2. Cài đặt thư viện (Dependencies)
Mở terminal (Command Prompt / PowerShell / Terminal trên VS Code) tại thư mục dự án và chạy:
```bash
npm install
```

### 3. Chạy môi trường phát triển (Development)
```bash
npm run dev
```
Trình duyệt sẽ tự động mở trang web tại `http://localhost:3000` hoặc cổng được hiển thị trên terminal.

### 4. Đóng gói cho Production
```bash
npm run build
```
Thư mục `dist/` sẽ được tạo ra chứa mã nguồn HTML, CSS, JS đã được tối ưu, sẵn sàng deploy lên Vercel, Netlify, GitHub Pages hoặc Web Hosting.

## 🛠️ Công nghệ sử dụng
- **React 19** & **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Bộ icons hiện đại)
- **EmailJS** (Gửi form liên hệ)
